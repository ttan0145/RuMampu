# US2.2 验收记录：典型与极端月份

语言：[English](US2.2_TYPICAL_AND_EXTREMES.md) | **中文（CN）**

| 验收标准 | 状态 | 实现与证据 |
| --- | --- | --- |
| AC2.2.1 显示平均收入 | 通过 | 服务只对已结束月份返回 Decimal 平均数；页面突出显示该值。 |
| AC2.2.2 显示中位收入 | 通过 | 根据已结束月数为奇数或偶数取排序后的中间值。 |
| AC2.2.3 显示最高收入 | 通过 | 以两位小数字符串返回已结束月份中的最高值。 |
| AC2.2.4 显示最低收入 | 通过 | 已结束月份的最低值独立于分类规则返回。 |
| AC2.2.5 标识计算结果 | 通过 | 每项统计均显示“计算所得”，API 返回 `calculated_from_user_record`。 |
| AC2.2.6 解释波动 | 通过 | 页面通过记录范围解释差异，不附加定性风险带。 |
| AC2.2.7 Show the recorded range [v24] NEW | 通过 | 记录范围作为单独标注的统计项展示，并与仅使用已结束月份的 API 结果一致。 |
| AC2.2.8 Show every recorded month [v24] NEW | 通过 | 已结束月份的 bar 位于横向滚动图内；当图表宽于可视区域时，显示滚动提示。 |

一到两个已结束月仍显示事实性统计，并附有限历史提示。当前未结束月份不参加六项统计，而是单独显示为“本月至今”。固定 12 个月场景验证 average `4437.50`、median `4385.00`、highest `5870.00`、lowest `3160.00`、range `2710.00`、population standard deviation `699.16`。
