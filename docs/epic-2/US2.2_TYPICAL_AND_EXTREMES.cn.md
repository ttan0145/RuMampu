# US2.2 验收记录：典型与极端月份

语言：[English](US2.2_TYPICAL_AND_EXTREMES.md) | **中文（CN）**

| 验收标准 | 状态 | 实现与证据 |
| --- | --- | --- |
| AC2.2.1 显示平均收入 | 通过 | 服务返回 Decimal 平均数；页面将其作为首要信息。 |
| AC2.2.2 显示中位收入 | 通过 | 奇数与偶数月分别取排序后的中间值或两个中间值平均。 |
| AC2.2.3 显示最高收入 | 通过 | 记录最大值以两位小数字符串返回。 |
| AC2.2.4 显示最低收入 | 通过 | 记录最小值独立于任何分类规则返回。 |
